Operação & Automação

BackOffice — Correção automatizada

De requisições manuais no Postman para um botão dentro do próprio sistema

  • API REST
  • Backend
  • CRUD
  • Integração de sistemas

Contexto

Parte da base de clientes tinha cadastros antigos no banco de dados de um sistema parceiro, anteriores a regras atualmente usadas pela operação.

Problema

Esses cadastros antigos podiam impedir a criação correta de novos IDs pelo sistema, travando o atendimento até que a inconsistência fosse corrigida.

Processo anterior

A correção era feita manualmente, com requisições diretas via Postman contra a API do parceiro — um processo que dependia de conhecimento técnico específico e não fazia parte da interface usada no dia a dia pela equipe.

Solução

Foi criada uma funcionalidade no próprio BackOffice — o botão "Corrigir ID" — que executa a mesma correção via API, agora diretamente pela interface que a equipe já utiliza.

Arquitetura

BackOffice → API REST → Correção do cadastro

Tecnologias

  • API REST
  • Backend
  • CRUD
  • Integração de sistemas

Resultado

  • Elimina a dependência do Postman para essa correção.
  • Centraliza o processo na própria ferramenta operacional da equipe.
  • Simplifica uma tarefa que antes exigia conhecimento técnico específico da API.
